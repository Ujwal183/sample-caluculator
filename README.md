# Calculator

A responsive browser-based calculator built with plain HTML, CSS, and JavaScript. It supports common arithmetic operations with both on-screen buttons and keyboard input.

## Features

- Addition, subtraction, multiplication, and division
- Clear all and delete the latest digit
- Decimal input
- Keyboard support for numbers, operators, Enter, Backspace, and Escape
- Readable number formatting
- Division-by-zero warning
- Responsive layout with button animations

## Run locally

No build tools or dependencies are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/Ujwal183/sample-caluculator.git
   ```
2. Open `index.html` in a web browser.
